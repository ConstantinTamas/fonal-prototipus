# Fonal: kattintható prototípus

Egy klinikai betegút-menedzsment rendszer kattintható prototípusa.

**Megnyitás:** https://constantintamas.github.io/fonal-prototipus/

- Minden adat kitalált: a betegek, a munkatársak és a TAJ-számok is. A TAJ-számok szándékosan érvénytelenek.
- A belépőlapon választod ki, kinek a nevében lépsz be. Ott vannak a forgatókönyvek lépései is.
- A próba a böngésződben fut, és az állapotot is ott tárolja. Amit itt csinálsz, azt más nem látja. A belépőlapon visszaállítható az alapállapot.
- Chrome-ban ellenőriztük.
